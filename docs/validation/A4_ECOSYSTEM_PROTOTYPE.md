# A4 — First isolated technical solver
This is a bounded fictional-fixture solver, not a real recommender. It does not expose any UI or promotion API, modify stable routes or catalogue, score 10D/97P, or assert verified context compatibility. The actual 34 A3 documentary leads are explicitly excluded from operational recommendations. Budget is integer MAD for the same explicit period, device slots are coarse before/during/after, conservative simultaneous sum per slot; no fine-grained schedule or real interoperability proof. Fixture gates are supplied test data, not evidence. The prototype exhaustively enumerates up to the stated bound; incomplete search suppresses selected result. Objective: mandatory coverage, then count, load, cost, deterministic IDs; optional coverage reported, not optimized. The simple comparator is best feasible set of at most two from same pool, not a validated baseline, and no historical-engine comparator is implemented yet. Independent small bitmask oracle tests cost/coverage only. Further work: verified evidence adapter and authorized real inputs, explicit timing/dependencies/transfers, comparison with historical engine, external review. No new source imports, weights, release or deployment. See research PLAN_APPLICATION_A4_V01.md.
