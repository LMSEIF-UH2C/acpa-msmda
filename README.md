# ACPA/MSMDA

Repository associated with Youness Moudettir's doctoral thesis at ENS Casablanca, Université Hassan II de Casablanca (LMSEIF).

The system described in the thesis assists physical education teachers in selecting technological teaching tools according to their teaching context.

## Current contents and scope

The current branch contains the repository documentation, the MIT License and the NOTICE file. It does not contain a runnable release of the ACPA/MSMDA system described and evaluated in the thesis.

This repository is intended to host selected non-critical components, including natural-language preprocessing and the user interface. Their release remains planned; the presence of a license file does not mean that these components are already available.

## Earlier demonstration code

The Git history retains an earlier Streamlit demonstration, a rule-based exercise recommendation engine, synthetic demonstration data and tests. These files were removed from the main branch in commit `3eff134b48beef4b67d02654aed692cd618b99fe`.

That demonstration recommends physical exercises. It is not the implementation of the technological tool selection system evaluated in the thesis and should not be used to reproduce its reported results.
