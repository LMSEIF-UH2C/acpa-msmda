# ACPA/MSMDA

Context-aware selection of educational technology tools for physical education.

ACPA/MSMDA assists physical education teachers in selecting technological teaching tools according to their teaching context.

## Current contents and scope

This repository contains documentation, the MIT License and the accompanying NOTICE. The release of selected non-critical components, including natural-language preprocessing and the user interface, is planned. No runnable ACPA/MSMDA release is currently available here.

## Earlier demonstration code

The Git history retains an earlier Streamlit demonstration, a rule-based exercise recommendation engine, synthetic demonstration data and tests. These files were removed from the main branch in commit `3eff134b48beef4b67d02654aed692cd618b99fe`.

That demonstration recommends physical exercises; it is distinct from the ACPA/MSMDA system for selecting educational technology tools.
