# ACPA/MSMDA: open-source components

This repository is the space announced in the doctoral thesis of
Youness Moudettir for publishing, under the MIT License, the
non-critical components of the ACPA/MSMDA system (natural-language
preprocessing and user interface).

## Status
No component has been published yet.

No. 74877, filed on 23 April 2026 (pending).
Inventor: Said Lotfi. Co-inventors: Youness Moudettir, Siham Ouhrir.
