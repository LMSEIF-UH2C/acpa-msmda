# A2 — isolated persistent technology library
The v0.2.0 release and current legacy paths remain the stable default. This branch adds a separate opt-in experimental library, not a new recommender. Build the SQLite file outside the repository:
```sh
python scripts/build_experimental_register.py --db /tmp/acpa-experiment.sqlite --date 2026-11-28
ACPA_EXPERIMENTAL_ECOSYSTEM=1 ACPA_EXPERIMENTAL_DB=/tmp/acpa-experiment.sqlite streamlit run app.py
```
Without the exact flag value 1 the additional route and button are absent. No automatic switch. The stable pages, data and scorer do not use the SQLite file. The experimental route reads only; it shows source links, original category/type codes and a not-assessed warning. No student data, new collection, raw descriptions, new scores, automatic deduplication, or recommendation promotion. The 34 documentary records are minimal project-authored pointers already published in the two research pilot reports, not 34 new products: overlap is unresolved. Other source imports remain blocked pending P2-15 and scientific gates. The register preserves 2466 local source records and 34 pointers as separate namespaces, observation changes append, repeated import is idempotent, conflicting immutable records roll back. This is a local prototype, not tamper-proof storage or authorization to distribute external datasets. The flag is a deployment switch, not authentication; external test deployment must be separately access-controlled if necessary. No DB committed; no merge or public deployment.
